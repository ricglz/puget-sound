# Puget Sound

**Seattle's transit, playing itself.**

Each bus line is a voice. Each stop, a note. When a bus arrives at a station, it triggers a musical note — creating an ever-changing, unscripted soundscape shaped by the city's actual transit patterns. During rush hours the output is dense and overlapping; at night, the pace slows and gaps of silence emerge. No two listening sessions are ever identical.

## Inspiration

Inspired by [@heliouz_](https://www.instagram.com/reels/DYSMK3xxzuP/) and [El Organillero](https://organillero.heliouz.com/) — a live map of Mexico City's Metrobús that turns bus arrivals into a generative musical composition.

## Tech stack

- **FastAPI** — backend proxy for GTFS-realtime feeds
- **Tone.js** — audio synthesis with PolySynth, reverb, and weighted random durations
- **Leaflet** — map with CartoDB dark tiles
- Vanilla ES modules, no build system

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r backend/requirements.txt

cd backend
python process_gtfs.py
uvicorn main:app --reload
```

Open http://localhost:8000.

The app starts in **demo mode** by default, simulating vehicle movement along real Seattle routes. Set `DEMO_MODE=false` to use live vehicle positions from King County Metro.

## Routes

Demo data includes a curated set of high-activity Puget Sound transit routes: RapidRide A/B/C/D/E/F/G/H lines, frequent Seattle bus routes, Sound Transit Express routes 522, 542, 545, 550, 554, 556, 566, and 570, Seattle streetcars, Link light rail, Tacoma Link, and Sounder N/S lines.

The **Everything** preset means every route included in this curated generated dataset, not every route published in the public GTFS feeds.

Route data is generated by `backend/process_gtfs.py` from public GTFS feeds. The generated `backend/data/transit_data.json` file is intentionally ignored by git; rerun the processor when the curated route list changes or the feed data needs a refresh.
